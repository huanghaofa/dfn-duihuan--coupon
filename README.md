# GUI 商品兑换券 App 端原型

这是 DFN 通用兑换券中“GUI 皮肤商品”场景的独立 App / 微信小程序前端演示。UI 继承原通用兑换券原型，只覆盖卡包、券详情、商品详情与选择、确认兑换，以及兑换后卡券详情。

## 演示范围

- 商品权威来源：产品中心。
- 一期商品范围：仅 GUI 皮肤；未上架但标记为可兑换的 GUI 商品仍可选。
- 用户选择粒度：SKU/规格；演示为 5 选 2、允许重复 SKU，库存为0不可选。固定兑换、N 选 M 和重复 SKU 配置在右侧标注说明。
- 用户车辆：页面回显用户默认会员卡中的车型与 VIN；不展示车牌号，兑换时不再选车。
- 履约路径：卡券中心 → 新商城代理 → 车联网后台 → 车机。
- 兑换结果：同一请求同步返回逐商品终态；全部成功或部分成功后在卡券详情展示结果，全部失败时留在确认页弹出“核销失败”。
- C 端展示：卡包统一显示“兑换券”；确认页只保留商品、车辆和确认按钮；部分成功中的失败商品只提供“联系客服”；全部失败直接反显车联网失败原因。
- 原型标注：右侧抽屉默认展开，可收起；点击标注可定位对应页面元素。

不包含运营后台、后台产品中心选品、后台履约查询、独立履约结果、兑换记录、独立系统时序，以及直邮、收货地址、物流、门店核销、E3S、会员和流量商品。

## 使用方式

打开 `index.html` 即可浏览；通过 HTTP 服务或 GitHub Pages 打开时体验更稳定。

本仓库是静态交互原型，页面中的商品、VIN、订单及履约数据均为演示 Mock，不代表真实接口联调或生产状态。
